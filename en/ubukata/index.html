Software

UbuKit

A clustering and self-organizing map library for Python and JavaScript. Besides k-means, fuzzy and rough clustering and SOM, it provides evaluation metrics and parameter search with TPE.

View on GitHub →
SOM-OLP

A Python implementation of a self-organizing map (SOM) that jointly learns the latent positions of data and the reference vectors. It includes a minimal implementation based on the paper and examples of training and visualization.

View on GitHub →
