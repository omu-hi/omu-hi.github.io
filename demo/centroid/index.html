01

「距離の2乗和」を分解する

1本の線について

横と縦のずれを、それぞれ2乗

dᵢ² = (xᵢ − pₓ)² + (yᵢ − pᵧ)²

データ xᵢ = (xᵢ, yᵢ) と代表点 p = (pₓ, pᵧ) の距離を dᵢ とします。三平方の定理から、距離の2乗は横と縦のずれの2乗を足したものです。

すべての線について

2乗した値を、全部足す

J(p) = ∑ dᵢ² = d₁² + d₂² + ⋯ + dₙ²

n はデータの個数です。先に各距離を2乗し、そのあと合計します。遠いデータほど大きく効き、距離が2倍なら、そのデータの寄与は4倍になります。

02なぜ、重心で最小になる？＋

重心は、横と縦それぞれの平均。

mₓ = (x₁ + x₂ + ⋯ + xₙ) / n
mᵧ = (y₁ + y₂ + ⋯ + yₙ) / n

この点を m = (mₓ, mᵧ) とすると、どこに代表点 p を置いても、次の関係が成り立ちます。

J(m)重心での2乗和
+
n ‖p − m‖²重心から離れた分の増加

‖p − m‖ は代表点から重心までの距離です。最後の項は必ず0以上で、代表点が重心に一致したときだけ0になります。だから、重心は距離の2乗和を最小にする唯一の位置です。

データがばらついていれば、重心に置いても最小値は0にはなりません。代表点は、実際のデータ点のどれかである必要もありません。

式の導出も見る

横方向だけを考え、ずれを次のように分けて2乗します。

xᵢ − pₓ = (xᵢ − mₓ) + (mₓ − pₓ)
∑(xᵢ − pₓ)² = ∑(xᵢ − mₓ)² + 2(mₓ − pₓ)∑(xᵢ − mₓ) + n(mₓ − pₓ)²

平均からのずれの和 ∑(xᵢ − mₓ) = 0 なので、中央の項は消えます。縦方向も同じように展開して足すと、上の式になります。

1個ずつ、左右のまとまりへ動かしてみよう。

重心の学びが、ここにつながる

全体の平均を1個から、それぞれの平均を1個ずつへ。

2つのまとまりに代表点を置くと、それぞれの近くにあるデータを代表できます。ボタンを押すと、その時点で担当しているデータの重心へ各代表点が移動します。

  1. 各データを、近い代表点に割り当てる。
  2. 各代表点を、担当するデータの重心へ動かす。

移動後は、また近い代表点を選び直します。この「割り当て」と「重心への移動」の繰り返しが、k-meansの基本です。

2個にしても、置き方によっては1個の最小値より誤差が大きくなります。1回の重心更新で全体の最適解になるとは限りません。距離が同じなら代表点1に割り当て、担当が0個の代表点はその位置に残します。
