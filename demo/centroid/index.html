01

「距離の2乗和」を分解する

1本の線について

横と縦のずれを、それぞれ2乗

di2 = (xi − px)2 + (yi − py)2

データ (xi, yi) と代表点 (px, py) の距離を di とします。三平方の定理から、距離の2乗は横と縦のずれの2乗を足したものです。

すべての線について

2乗した値を、全部足す

J(p) = d12 + d22 + … + dn2

n はデータの個数です。先に各距離を2乗し、そのあと合計します。遠いデータほど大きく効き、距離が2倍なら、そのデータの寄与は4倍になります。

02なぜ、重心で最小になる？＋

重心は、横と縦それぞれの平均。

mx = x1 + x2 + … + xnn my = y1 + y2 + … + ynn

この点を m = (mx, my) とすると、どこに代表点 p を置いても、次の関係が成り立ちます。

J(p)現在の2乗和
=
J(m)重心での2乗和
+
n ‖p − m‖2重心から離れた分の増加

‖p − m‖ は代表点から重心までの距離です。最後の項は必ず0以上で、代表点が重心に一致したときだけ0になります。だから、重心は距離の2乗和を最小にする唯一の位置です。

データがばらついていれば、重心に置いても最小値は0にはなりません。代表点は、実際のデータ点のどれかである必要もありません。

式の導出も見る

横方向だけを考え、xi − px = (xi − mx) + (mx − px) と分けて2乗します。

∑i=1n (xi − px)2
= ∑i=1n (xi − mx)2 + 2(mx − px) ∑i=1n (xi − mx) + n(mx − px)2

平均からのずれの和 ∑(xi − mx) は0なので、中央の項は消えます。縦方向も同じように展開して足すと、上の式になります。
